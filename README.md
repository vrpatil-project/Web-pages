# Task 2 - Employee Details Card
This project is a simple Employee Details Card created using basic HTML tags.
It displays employee information such as company name, employee name, designation, department, experience, skills, joining date, and examples of superscript and subscript tags.
This task helped me practice HTML text formatting and page structure.
## HTML Tags Used
- Heading Tags (h1, h2)
- Paragraph (p)
- Bold (b)
- Strong (strong)
- Italic (i)
- Mark (mark)
- Superscript (sup)
- Subscript (sub)
- Horizontal Rule (hr)
